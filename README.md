# Lesson: Java Basics
[Want to go back to try it yourself?](https://github.com/LucianWhisper/JavaTutorials/tree/java-basics)

## Goal
Introduce programming and Java to someone who has **never written code before**.

By the end of the tutorial, you should understand:
* What a program is
* What Java is
* Where a Java program starts
* How to print information
* What a method is
* What a variable is
* What a class is
* What an object is
* What an instance is
* What access modifiers do
* What `static` means at a basic level
* The basic difference between a CPU and GPU

The goal is **understanding**, not memorizing terminology.

## Key Information
Some key and important topics covered in this tutorial, for reference and remembering:
* **Programming** is the process of writing instructions for a computer to execute.
* A **program** is a collection of instructions that tells a computer what to do.
* **Java** is a programming language used to write programs.
* The `main` method is the **starting point** for a standard Java application.
* A **statement** is an instruction that the program executes.
* A **method** is a named block of code that can be called to perform a task.
* A **variable** is a named piece of data that can hold a value.
* A **class** defines the structure and behavior of a type of object.
* An **instance** is a specific object created from a class. A single class can have many instances, each with its own data.
* **Access modifiers** control what parts of a class can be accessed from other code.
* `static` means a member belongs to the **class itself**, rather than to a specific instance.
* The **CPU** is a general-purpose processor responsible for executing program instructions and many other tasks.
* The **GPU** is specialized for performing large numbers of calculations in parallel, making it especially useful for graphics and other parallel workloads.
